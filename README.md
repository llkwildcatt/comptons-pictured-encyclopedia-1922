# Compton's Pictured Encyclopedia, c1922

Companion site to [Webster's 1828 Dictionary](https://llkwildcatt.github.io/webster-1828-dictionary/).
Compton's Pictured Encyclopedia, 1st edition, c1922, in seven article volumes — 2,736 articles, cleaned up word by word
from scans of the printed books, with the book's full-page plates
(maps, portraits, pictures) shown with their articles. Volume 8 (study outlines and Fact-Index) holds no articles.

The main site can only hold so much on its free hosting, so this book
has a site of its own. The two sites link to each other.
